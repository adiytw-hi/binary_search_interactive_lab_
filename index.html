Self-tests have not been run in this session.
Assumptions: Integers are sorted in strictly increasing order; each access and comparison is counted as one search check; indices start at zero. For even lengths, the lower of the two central elements is chosen first via floor((left + right) / 2). “Not found” occurs when left > right. Linear search scans left to right. The simulation is for algorithm understanding, not a CPU timing benchmark. No data leaves this browser.
